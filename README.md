# Particle Phenomenology Lab

Academic portfolio of small, documented particle-phenomenology projects in Python.

The repository is organized as a collection of self-contained projects. The first project is `llp-acceptance-lab`, a toy but physically honest study of long-lived-particle decay probabilities and detector acceptances.

## Projects

- [`llp-acceptance-lab`](./llp-acceptance-lab): relativistic kinematics and 1D LLP decay probabilities, with tests, notebooks, and a LaTeX report scaffold.

## Scope

These projects are educational phenomenology tools. They do not use real experimental efficiencies, do not quote exclusions, and do not claim to simulate ATLAS, CMS, FASER, or any other detector.
